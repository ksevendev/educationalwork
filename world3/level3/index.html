Relatório do Projeto - Cadastro de Pessoas

1. Introdução

Este projeto tem como objetivo desenvolver um sistema de cadastro de pessoas físicas e jurídicas utilizando Java com JDBC e SQL Server. Ele permite a inserção, consulta e gerenciamento dos dados de forma estruturada.

2. Tecnologias Utilizadas

  • Java SE 8+
  • NetBeans IDE
  • SQL Server
  • JDBC (Java Database Connectivity)

3. Estrutura do Banco de Dados

As tabelas do banco de dados foram criadas da seguinte forma:

Tabela Campos
Pessoa id (PK), nome, logradouro, cidade, estado, telefone, email
PessoaFisica id (FK), cpf
PessoaJuridica id (FK), cnpj

4. Arquitetura do Projeto

O projeto segue uma estrutura baseada em camadas:

  • cadastrobd.model: Contém as classes de modelo (POJOs).
  • cadastrobd.dao: Contém as classes DAO para manipulação do banco de dados.
  • cadastrobd.util: Contém a classe ConectorBD para a conexão com o SQL Server.
  • cadastrobd: Contém a classe principal para testes.

5. Funcionamento do Sistema

O sistema permite:

  • Cadastro de Pessoas Físicas e Jurídicas.
  • Listagem de todas as pessoas cadastradas.
  • Persistência dos dados no SQL Server.

6. Conclusão

Este projeto demonstra a integração entre Java e SQL Server, utilizando boas práticas como DAO e JDBC. Ele pode ser expandido para incluir funcionalidades como atualização e remoção de registros.
